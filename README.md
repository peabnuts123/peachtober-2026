# Peachtober 2026

This is an experimental project to participate in [Peachtober](https://www.furrylittlepeach.com/peachtober) through a singular "game" that evolves every day.

> Peachtober is an annual community challenge I created in 2018 based on Inktober. Every year thousands of artists come together to participate and create an artwork every day in October based on these prompt lists.
